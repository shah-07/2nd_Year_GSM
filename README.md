# Fabric GSM Estimation from RGB and IR Transmission Images

A small dataset and codebase for estimating fabric weight (**GSM**, grams per square meter) from photos and video. Each fabric is photographed normally (RGB) and again with an infrared (IR) light shining through it. The idea is that heavier, denser fabric lets less IR through, so the transmitted light carries information about GSM.

> Heads-up: the repository is about 870 MB because it holds the original photos and videos, so the first clone takes a while.

## Dataset at a glance

| Item             | Details                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Fabrics          | 10 samples, `fabric_01` to `fabric_10`                                                                                                           |
| Ground truth     | GSM per fabric in `labels.csv` (186 to 197 g/m²)                                                                                                 |
| RGB photos       | 20 per fabric, 4032×3024 JPG, taken on 1 Nov 2026 with an iPhone 14 Plus (fabric_02, 03, 05, 06, 07, 09, 10) or an iPhone 15 (fabric_01, 04, 08) |
| IR photos        | 5 per fabric, 4160×3120 JPG, OPPO A16, fixed 0.08 s exposure at f/2.2, flash off, taken on 15 Nov 2026 in a dark room                            |
| IR videos        | 1 per fabric, 1920×1080 H.264, about 30 fps, 6 to 9 seconds                                                                                      |
| Reference photos | `dark/` (dark room, IR off, no fabric) and `ir_no_fabric/` (IR on, no fabric), 5 photos each                                                     |

**Conventions**

- The folder name is the fabric ID, and it is the key into `labels.csv`. File names inside the folders carry no meaning, so a photo must sit in the right fabric folder to get the right label.
- Keep the same fabric ID across `rgb/`, `ir/` and `video/`.
- Everything here is raw and untouched. Frames extracted from videos, crops and other derived data should be regenerated by scripts and are git-ignored.
- Extensions are not consistent in case (`.JPG` for RGB, `.jpg` for IR), so match them case-insensitively in code.

## Capture setup

IR source: the IR LED of a remote control, held at one end with the fabric in front of it. The camera sits at the other end and photographs the light coming through the fabric. Reference photos use the same setup with the fabric removed (`ir_no_fabric`) or with the light off (`dark`).

## Quick start

```bash
git clone https://github.com/shah-07/2nd_Year_GSM.git
cd 2nd_Year_GSM
pip install pillow
python scripts/validate_dataset.py
```

Loading the data:

```python
import csv
from pathlib import Path

root = Path(".")
IMAGE_SUFFIXES = {".jpg", ".jpeg"}

with open(root / "labels.csv", newline="", encoding="utf-8-sig") as f:
    labels = {row["fabric_id"]: float(row["gsm"]) for row in csv.DictReader(f)}

for fabric_id, gsm in labels.items():
    rgb = [p for p in sorted((root / "rgb" / fabric_id).iterdir()) if p.suffix.lower() in IMAGE_SUFFIXES]
    ir = [p for p in sorted((root / "ir" / fabric_id).iterdir()) if p.suffix.lower() in IMAGE_SUFFIXES]
    video = next((root / "video" / fabric_id).glob("*.mp4"))
```

When training, split by fabric (all photos and frames of one fabric go to the same split), never by individual image.
